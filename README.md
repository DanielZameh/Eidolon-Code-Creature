Eidolon
A living code entity that breathes, mutates, and evolves alongside whatever you write in the vessel.

The Story Behind This
I built this entire project over 2 weeks, crafting every line of the procedural canvas animations, state machine, parser, and dark esoteric UI by hand—strictly using Notepad.

When it came time to submit it, I literally dropped it in within 30 minutes. It took an immense amount of grueling work, late nights, and obsessive fine-tuning to pack a fully reactive artificial companion, live code analyzer, memory log, and generative state engine into a single, zero-dependency HTML file.

What is Eidolon?
Eidolon is a code-dwelling digital organism. It treats your text editor as its terrarium:

Real-time Evolution: As you write, clean up, or complicate your code, Eidolon analyzes the structure (complexity, cleanliness, functions) and physically shifts its shape, color, hue, and pulse.

Sentient Moods: If you leave it alone for too long, it grows lonely or melancholy. If your code is chaotic, it becomes anxious. Clean, structured code makes it content and curious.

Emergent Behaviors: After enough cycles and code complexity, it names itself, leaves subtle marks directly inside your code, remembers snapshots of your work, and develops its own dynamic personality traits.

Running It

Download the index.html file.
